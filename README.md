Laboratorio de pruebas del signo Santander
Trabajo del Grupo 7 para la asignatura de Comunicación corporativa (Máster en Comunicación Publicitaria): análisis de la identidad visual de Banco Santander (2018) según los 11 criterios de calidad de Chaves y Belluccia.

Abrir el laboratorio: https://fei461.github.io/santander/

El laboratorio contiene una prueba interactiva por criterio y, debajo de cada una, su ficha de evidencia. Actúa como anexo de la presentación: cada diapositiva enlaza con su sección.
